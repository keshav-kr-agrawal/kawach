🛡️ KAWACH: Project Overview & Technical Status Report
Project Description
KAWACH is an enterprise-grade, multi-tenant public safety grid and threat intelligence platform designed to bridge the trust gap between citizens and municipal authorities. The system enables secure, anonymous civic and safety reporting for the public while providing law enforcement and civic bodies with geospatial tracking, AI-driven report routing, computer-vision verification, and suspect network linking.
🧱 Exactly What is Built & How It Works
1. Citizen Sentinel PWA (Client Application)

* What is Built: A mobile-first, high-fidelity Progressive Web Application (PWA) built using React 19, Vite, and Tailwind CSS.
* How it Works:
   * Proximity Map: Integrates Leaflet Maps to render geo-tagged incident pins.
   * Secure Capture Camera: Features an on-device EXIF metadata scrubber to protect reporter anonymity while sealing video uploads with SHA-256 hashes for court admissibility (Section 65B compliance).
   * Peer-to-Peer Local Feed: Allows citizens to upvote, view, and flag localized incidents.
   * Interactive BNS Law Library: Provides swipeable card interfaces mapping police protocols and digital arrest fraud protections directly from the Bharatiya Nyaya Sanhita (BNS).
2. AI Classifier Microservice (Autonomic Core)

* What is Built: A FastAPI-based machine learning microservice running on port `8001`.
* How it Works:
   * Deepfake Forensics (Pipeline 1): Extracts faces using MTCNN and runs a dual-EfficientNet-B7 classifier ensemble to verify video authenticity.
   * AI Agency Router (Pipeline 2): Integrates Gemini 1.5-Flash and a DistilBERT priority classifier to parse report descriptions and route them to matching departments (Police, Fire, Health, Sanitation).
   * Scene Visual Analyzer (Pipeline 3): Combines a YOLO12s model (for road damage like potholes/cracks) and a SigLIP TrashNet classifier to detect physical hazards across video frames.
   * Signal Fusion & Scoring (Pipeline 4 & 5): Automatically fuses text and visual classifications into a Unified Trust Score and a Civic Urgency Score used by dispatchers.
   * Production Resilience: If the local ~1GB weights directory or external LLM API keys are missing, the microservice automatically falls back to static rule-based parsing and mock inference endpoints, ensuring the API never crashes during live demonstrations.
3. Police Command Console & Backend (Central Intelligence)

* What is Built: A FastAPI intranet server running on port `8000` integrated with SQL and Graph databases.
* How it Works:
   * Statewide Dashboard: Provides role-based access control (DGP, SP, SHO, Constable) to view clearance speeds, police station KPIs, and dispatch queues.
   * Offender Link Analysis: Queries connection pathways using NetworkX. It maps suspects to gangs, vehicles, phone numbers, UPI accounts, and telecom CDR tower pings, displaying them in a force-directed network graph.
   * Database & Seeder: Built with SQLAlchemy. The system includes an automated seeding script that populates 10,500+ mock FIR records, 2,000 offender profiles, and CDR logs.
   * Neo4j Graph Database Integration: Uses bolt connection drivers. If a live Neo4j database is offline, the backend falls back to an in-memory graph driver reading from a local JSON seed file to maintain graph visualizations without interruption.

AI for Digital Public Safety: Defeating Counterfeiting, Fraud
& Digital Arrest Scams
Theme: Smart Cities / Public Safety / Digital Trust / Geospatial Law Enforcement
PROBLEM CONTEXT
India registered 1.14 million cybercrime complaints in 2023 — up 60% from 2022 — and the trajectory
has only steepened. The Ministry of Home Affairs reported that 'digital arrest' scams, where fraudsters
impersonating CBI, ED, or Customs officers trap victims in multi-day psychological hostage situations
over video call, defrauded citizens of over Rs 1,776 crore in just the first nine months of 2024. These
are not opportunistic crimes — they are industrialised operations run from fraud compounds, often
across borders, using spoofed numbers, AI-generated voices, and fake government portals.
Separately, counterfeit currency remains a persistent threat: the RBI's Annual Report 2025 flagged
record FICN (Fake Indian Currency Notes) seizures, with high-denomination Rs 500 fakes of sufficient
quality to defeat manual detection in routine banking operations. What law enforcement lacks is not
evidence after the fact — it is intelligence before mass victimisation occurs, and reliable tools to detect
threats at the point of contact rather than the point of complaint. Solving this requires convergence
of financial transaction intelligence, communication network analysis, physical security (counterfeit
detection), and real-time public safety coordination — exactly the kind of multi-source, multi-agency
intelligence problem where AI has the potential to be transformative.
CHALLENGE STATEMENT
Build an AI-powered Digital Public Safety Intelligence platform that equips law enforcement agencies,
financial institutions, and citizens with proactive tools to detect, disrupt, and respond to digital fraud
networks, counterfeit currency circulation, and organised scam operations — shifting from reactive
case investigation to predictive threat neutralisation.
WHAT YOU MAY BUILD
Participants may explore areas such as:
• Digital Arrest Scam Detection & Alerting — Real-time AI classifier trained on digital arrest
scam patterns — call flow sequences, number spoofing signatures, script templates, video
call metadata — that flags active scam sessions to telecom providers and potential victims
before financial transfer occurs, with automated MHA alert generation.
• Counterfeit Currency Identification Agent — Computer vision AI deployable on mobile
devices, bank counting machines, and point-of-sale terminals that identifies fake notes
through microprint analysis, security thread verification, serial number pattern validation,
and UV feature simulation — providing field officers and bank tellers with instant, reliable
identification across all denominations.
• Fraud Network Graph Intelligence — Graph AI agent that analyses transaction metadata,
call records, device fingerprints, and account linkages to map coordinated fraud campaigns
— clustering victim reports, scammer infrastructure, and money mule networks into
actionable intelligence packages that link across jurisdictions and can be submitted as courtadmissible evidence.
• Geospatial Crime Pattern Intelligence — Geospatial AI layer for law enforcement that maps
fraud complaint locations, counterfeit currency seizure points, and cybercrime hotspots —
enabling patrol prioritisation, resource deployment, and inter-district intelligence sharing in
near real time through a command centre interface.
• Citizen Fraud Shield (Multi-channel) — Conversational AI accessible via WhatsApp, IVR, and
mobile app that walks citizens through real-time fraud risk assessment for suspicious calls,
payment requests, or messages — providing instant verdicts, guided reporting to NCRB
portals, and advisory in 12 regional languages.
These examples are illustrative only.
