The doctrine

The boundary

A report crosses into this building carrying evidence, location, and urgency — never a name.

Department queues read a fixed set of identity-free columns. Who filed the report stays on the citizen side of the wall, permanently. What you act on is the incident itself: what happened, where, how bad, and how strong the evidence is.

R·01

Detection never files. Citizens do.

The classifier proposes; a person confirms. No queue entry exists that a citizen did not explicitly approve.

R·02

Identity stops at the wall.

Dashboards query only report content, coordinates, evidence, and classifier output. Reporter identity is not in the column list — by construction.

R·03

One shell, eleven desks.

Every department runs the same dashboard, parameterised by config. Same SLA math, same queue discipline, no favourites.

R·04

Honest when degraded.

If the live database is unreachable, the dot in the corner turns red and the grid runs on a simulated ledger — behaviorally identical, honestly flagged.

The clock

Four windows. No exceptions.

Priority is set upstream by classification — and floors apply: every fire report enters at the fifteen-minute tier, every police report at the four-hour tier or better. When a window closes unanswered, the report is marked breached and surfaces on the Master Console. There is no way to quietly let one expire.
